# Semantic Resources

Ontologies, vocabularies, code lists, data models, and reference materials that define
soil terms.

Each resource gets one card. Copy [template.md](template.md) and save it as `<slug>.md`,
where the slug is the resource's short name or acronym.

Use `# Terms of interest` to list soil-relevant classes and their identifiers
when the resource covers more than soils.
