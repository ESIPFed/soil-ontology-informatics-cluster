# Data Models

Schemas, exchange formats, and templates for representing and transmitting soil data.
These resources define the structure of soil data records rather than just the terminology.

# Data Models

* [INSPIRE Soil Theme Technical Guidelines](inspire-soil-guidelines.md) - EU INSPIRE technical guidelines for the soil spatial data theme
* [GloSIS Ontology](glosis-ontology.md) - FAO Global Soil Information System OWL data model
