# Description

GloSIS (Global Soil Information System) is an FAO initiative to create a global, interoperable soil information infrastructure. The GloSIS OWL ontology provides the formal data model that underpins this system, defining classes and properties for soil observations, soil profiles, soil horizons, and sampling procedures. It builds on OGC standards (notably O&M, the Observations and Measurements model) and is designed to align with the INSPIRE soil schema. The ontology is complemented by GloSIS codelists for both descriptive properties and chemical analysis procedures. One documented limitation is that the ontology currently focuses heavily on data model structure labels rather than formal semantic definitions for the concepts themselves. The source is maintained on GitHub and actively developed by the FAO Global Soil Partnership team.
