# Description

The INSPIRE Soil Theme Technical Guidelines define the data model and exchange specifications for soil data under the EU INSPIRE Directive. INSPIRE (Infrastructure for Spatial Information in the European Community) mandates that EU member states publish spatial data, including soil data, in interoperable formats according to common technical specifications. The soil theme technical guidelines specify the conceptual model (based on ISO 28258 and FAO/ISRIC standards), feature types, attribute definitions, and encoding rules for soil spatial datasets. Implementation requires transformation of national soil data into the INSPIRE Soil application schema, which covers soil body, soil profile, soil layer, and soil derived objects. The guidelines are implemented by the European Soil Data Centre (ESDAC) and national environmental agencies across EU member states.
