# Description

AGROVOC is FAO's multilingual agricultural thesaurus, covering food, agriculture, fisheries, forestry, and natural resources in more than 40 languages. Soil is a significant domain within AGROVOC, with terms covering soil types, soil properties (e.g., soil pH, soil organic matter, cation exchange capacity), soil management, and soil processes. AGROVOC is published as a SKOS Linked Data resource with persistent HTTP URIs for each concept, making it suitable for semantic annotation and cross-system interoperability. It is linked to other controlled vocabularies including NALT and EUROVOC, enabling term alignment across jurisdictions. AGROVOC is curated collaboratively with contributions from national institutions and is maintained by FAO's Libraries and Documentation Systems Division.
