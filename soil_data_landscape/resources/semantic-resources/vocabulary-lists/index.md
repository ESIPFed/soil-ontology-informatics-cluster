# Vocabulary Lists

Controlled term sets, thesauri, and code lists providing standardized soil terminology.
Unlike full ontologies, these focus on term definitions and hierarchies rather than
formal axioms and inference.

# Vocabularies

* [USDA Agricultural Thesaurus and Glossary](usda-agricultural-thesaurus.md) - USDA-NAL controlled vocabulary covering agriculture including soil science
* [USGS Thesaurus](usgs-thesaurus.md) - USGS science thesaurus with soil-related terms across multiple disciplinary categories
* [FAO AGROVOC](agrovoc.md) - FAO multilingual agricultural thesaurus with soil terms in 40+ languages
* [GloSIS Codelists — Descriptive Properties](glosis-codelists-descriptive.md) - FAO Global Soil Partnership code lists for descriptive soil properties
