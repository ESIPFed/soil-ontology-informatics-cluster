# Description

The GloSIS (Global Soil Information System) Codelists for descriptive properties provide controlled values for soil horizon designations, soil colour, texture class, structure type, and other field-observable soil attributes. They are published in RDF/Turtle format as part of the GloSIS linked data stack, which also includes the GloSIS OWL ontology and separate code lists for chemical analysis procedures. The descriptive codelists are designed to be directly populated into GloSIS-compliant data submissions and are intended to harmonize soil descriptions across national soil survey systems worldwide. As a linked data resource, each term has a persistent URI enabling machine-readable reference in soil profile databases and spatial data infrastructures.
