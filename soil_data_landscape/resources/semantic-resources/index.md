# Semantic Resources

Controlled vocabularies, ontologies, data models, and reference manuals that provide
the shared language needed to describe, find, and integrate soil data.

Each sub-folder corresponds to a distinct resource subcategory with its own OKF type.

# Subcategories

* [Ontologies](ontologies/) — Formal OWL/SKOS ontologies covering soil as a domain
* [Vocabulary Lists](vocabulary-lists/) — Thesauri, code lists, and controlled term sets
* [Data Models](data-models/) — Schemas, formats, and templates for soil data exchange
* [Manuals and Methods](manuals-and-methods/) — Reference manuals and field method guides
