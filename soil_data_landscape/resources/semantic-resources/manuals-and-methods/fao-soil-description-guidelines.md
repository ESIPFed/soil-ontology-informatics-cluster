# Description

The FAO Guidelines for Soil Description (4th edition, 2006) is the global standard reference for describing soil profiles in the field. It covers the systematic description of soil horizon designations, colour (using Munsell notation), texture, structure, consistence, coarse fragment content, pore distribution, biological features, and other morphological properties. The guidelines are designed to be compatible with both the World Reference Base for Soil Resources (WRB) and the US Soil Taxonomy, making them applicable to international soil survey projects and data harmonization efforts. They provide the descriptive vocabulary and procedure basis for field campaigns whose data ultimately populates resources like WoSIS, GloSIS, and national soil databases. Understanding this manual is essential for interpreting legacy soil profile data collected under FAO conventions.
