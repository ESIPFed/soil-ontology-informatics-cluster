# Description

The Soil Survey Laboratory Methods Manual is the authoritative reference for the laboratory analytical methods used by the USDA Kellogg Soil Survey Laboratory (KSSL) and the National Cooperative Soil Survey (NCSS). It documents method codes, analytical procedures, quality control protocols, and result interpretation for a comprehensive suite of soil properties including particle size distribution, bulk density, pH, organic carbon, cation exchange capacity, extractable nutrients, and many others. The method codes in this manual correspond directly to the analytical codes used in the NCSS lab database and the NASIS (National Soil Information System) metadata, making it an essential reference for interpreting USDA soil survey data. Companion NCSS metadata files on GitHub provide a machine-readable snapshot of these method codes.
