# Manuals and Methods

Reference manuals, field guides, and method documentation for soil description,
classification, and laboratory analysis. These resources define standard methods and
terminology used to generate soil data.

# Manuals

* [World Reference Base for Soil Resources 2014](fao-wrb-2014.md) - FAO international soil classification reference, the global counterpart to national classification systems
* [Soil Survey Laboratory Methods Manual](usda-soil-survey-lab-methods.md) - USDA-NRCS authoritative reference for laboratory methods used in US soil surveys
* [FAO Guidelines for Soil Description](fao-soil-description-guidelines.md) - FAO global reference for standardized field description of soil profiles
* [Keys to Soil Taxonomy (current)](keys-to-soil-taxonomy.md) - USDA-NRCS working keys for classifying soils within the US Soil Taxonomy system
