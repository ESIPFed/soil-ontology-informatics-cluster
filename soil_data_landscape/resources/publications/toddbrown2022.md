# Description

Meta-analysis in soils typically compiles data using manual entry from individual studies. This paper surveys current practices across all stages of soil data synthesis — availability, input, harmonization, curation, and publication — and identifies bottlenecks at each step. The authors argue that soil data remain largely unusable for cross-study synthesis outside of a few large survey resources, and propose a suite of semantic tools to improve the pipeline: domain ontologies, controlled vocabulary lists, and community data conventions. The paper is a key reference motivating the Soil Ontology and Informatics Cluster's resource card work, as it frames the need for structured, machine-readable descriptions of soil data resources and standards.
