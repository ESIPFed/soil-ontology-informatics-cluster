# Data Holdings

Repositories, data portals, and archives with significant soil data holdings.
The resource described in each card is the holding itself (the repository or dataset collection),
not the organization that hosts it — see [Actors](/actors/) for the host organizations.

# Holdings

* [ESS-DIVE](ess-dive.md) - DOE repository for Environmental System Science data including soils from NGEE-Arctic, SPRUCE, and NGEE-Tropics
* [ISRIC Data Hub](isric-data-hub.md) - Global soil dataset catalog curated by ISRIC — World Soil Information
* [European Soil Data Centre (ESDAC)](esdac.md) - EU-wide soil datasets maintained by the EC Joint Research Centre
* [NASA ORNL DAAC Soil Holdings](ornl-daac-soil.md) - NASA-funded archive of biogeochemical and soil datasets
