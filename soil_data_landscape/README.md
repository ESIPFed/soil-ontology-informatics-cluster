# Soil data landscape scope

We want to create a list of all current soil informatics resources to increase awareness within the cluster and beyond. [Soil_data_landscape.md](https://github.com/ESIPFed/soil-ontology-informatics-cluster/blob/main/Soil_data_landscape.md) was initially created in 2021 and has been updated inconsistently over the years. We were initially looking for vocabularies, dictionaries (term-definition pairs), code lists (particularly method descriptions), and other semantic resources. This was then extended to data products themselves. There is also interest in monitoring networks and organizations.

We would like 
  * to move from the current free text formation to a more machine readable format, 
  * connect the machine readable formats to a dynamic/static web interface to increase discoverability of these resources,
  * set up a governance process to scope, maintain, and extend this collection including flagging stale links and adding new resources,
  * publicize this resource and engage feedback from stakeholders.
